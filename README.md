# Clipboard Image Monitoring and Saving（剪贴板图片监听保存）

一个基于 **AutoHotkey v2** 的剪贴板监听工具：当你在电脑上复制图片、图片链接或本地图片路径时，自动把图片保存为 PNG 文件；复制普通文本时则自动记录到日志，无需手动「另存为」。

## 解决的问题

平时从网页、聊天软件、截图工具等处复制图片时，图片只临时存在于系统剪贴板，稍纵即逝；要长期保存往往需要打开画图工具、粘贴、再另存为，操作繁琐且容易遗漏。

本项目通过监听系统剪贴板变化，实现「**复制即保存**」：

- 复制任意图片 → 自动保存为 PNG 到当前文件夹
- 复制图片链接 / 本地图片路径 → 自动下载并保存为 PNG
- 复制普通文本 → 自动追加到日志文件，方便回溯

## 主要功能

- **剪贴板监听**：通过 `OnClipboardChange` 实时监听系统剪贴板变化，全程后台运行。
- **图片自动保存**：剪贴板内容为图片（PNG / DIB / BMP 等格式）时，立即保存为 PNG。
- **智能识别来源**：自动判断剪贴板内容是「图片」、「图片 URL」、「本地图片路径」还是「普通文本」，分别处理。
- **保存到当前文件夹**：优先保存到当前活动的资源管理器窗口所在目录；没有可用资源管理器窗口时回退到脚本所在目录。
- **文本日志记录**：非图片文本追加到 `剪切板记录.txt`（UTF-8，带时间戳）。
- **多行处理**：一次复制多行（多个来源）时逐行识别处理。
- **编码兼容**：自动确保日志文件为 UTF-8 编码；历史非 UTF-8 日志会被转移到独立的「旧编码」文件，避免中文乱码。
- **状态提示**：启动、保存成功、处理失败等通过悬浮提示（ToolTip）即时反馈。
- **单实例运行**：避免重复监听导致重复保存或重复写日志。

## 安装方法

1. 安装 **AutoHotkey v2**：前往官网 <https://www.autohotkey.com/> 下载安装。
2. 确保脚本目录下包含 **ImagePut.ahk**（本项目已随仓库提供，版本 1.12，基于 [ImagePut](https://github.com/iseahound/ImagePut)）。
3. 双击运行 `剪切板图片监听保存.ahk`，脚本常驻系统托盘，即开始工作。

> 也可将脚本放入 Windows 启动文件夹，实现开机自启。

## 使用方法

运行脚本后，它会在后台持续监听剪贴板，无需任何额外操作：

| 你在别处复制的内容 | 脚本自动完成 |
| --- | --- |
| 图片（截图、网页图、聊天软件图片等） | 保存为 `剪切图片_时间戳.png` 到当前文件夹 |
| 图片链接，如 `https://example.com/a.png` | 下载并保存为 `剪贴图片_时间戳_1.png` |
| 本地图片路径，如 `D:\照片\a.jpg` | 复制保存为 PNG 文件 |
| 普通文本 | 追加到 `剪切板记录.txt`（带时间戳） |

> **保存位置**：优先为当前打开的资源管理器窗口所在目录；若无活动资源管理器窗口，则保存到脚本所在目录。

### 输入输出示例

**示例 1：复制图片**
- 输入：在浏览器或截图工具中复制一张图片（`Ctrl+C`）
- 输出：当前文件夹生成 `剪切图片_20261001_153000_123456.png`

**示例 2：复制图片链接**
- 输入：`https://example.com/photo.png`
- 输出：保存 `剪贴图片_20261001_153000_1.png`

**示例 3：复制本地图片路径**
- 输入：`D:\照片\a.jpg`
- 输出：保存 `剪贴图片_20261001_153000_1.png`

**示例 4：复制普通文本**
- 输入：`你好，这是一段说明`
- 输出：`剪切板记录.txt` 追加如下内容：

```text
[文本] 2026-10-01 15:30:00
你好，这是一段说明
------------------------------
```
